# Nate 1.0 Scope

Nate 1.0 is a beginner-friendly language for scripts, CLI tools, small
servers, and learning. It should feel as easy as Go, with safer defaults
and a smaller surface.

The interpreter is the product. The bytecode VM and LLVM backend are
faster paths, documented as preview until they match the frozen spec.

Current candidate: `v1.0.0-rc.1`. Stable target: `v1.0.0`.
All language sections and the listed module contracts are frozen for candidate
validation. `release.json` pins public exports and arities; `release_audit.py`
checks the inventory against source, specs, and executable test references.

## Product promise

A user who installs Nate 1.0 can:

1. Build from source on macOS and Linux.
2. Run `nate --version` and get `1.0.0`.
3. Write, run, test, and document `.nate` files.
4. Use the frozen language, stdlib, and CLI without surprises.
5. Read a language spec that matches the implementation.

A user cannot expect Sail, a package registry, GPU, WASM, mobile,
self-hosting, or a production AI agent platform.

## Frozen language

- Lexical syntax, comments, identifiers, literals
- Values: `nil`, `bool`, `int`, `float`, `string`, array, map, set
- `if` / `else`, optional `if init; cond`, `for` in all three forms
- `break`, `continue`, `switch` / `case` / `default`
- `func`, closures, `return`
- structs, methods, field access, struct literals
- interfaces and type assertion `x.(Type)`
- enums with values, `match`, `_`, rest patterns
- `import` modules
- error values, `or`, multi-assign `(value, err)`, `guard`
- `panic` and panic containment
- `spawn`, `concurrent`, `channel`, `send`, `receive`, `close_channel`
- index get and set: `m["key"]`, `arr[0] = v`

## Frozen stdlib

Documented public APIs only:

- `math`, `strings`, `collections`, `io`, `time`, `fmt`, `random`
- `json`, `testing`
- `option`, `result`
- `http` plain-text IPv4 client, request parser and text response builders

HTTP TLS, chunked-response decoding, automatic redirects, IPv6, and binary
bodies are unsupported. TCP socket wrappers, cookies, sessions, websockets,
rate limits, and extended validation are
preview even if the C builtins exist.

## Frozen CLI

```
nate                 REPL
nate run <file>      Run a file. No AST dump by default.
nate test [path]     Discover and run test_* functions
nate bench [path]    Discover and run bench_* functions
nate doc <file>      Text docs. HTML optional.
nate --version       Prints 1.0.0
nate --help          Lists frozen commands
```

## Preview in 1.0

Ships in the tree. Not a compatibility promise. May change.

- Bytecode VM: `nate run --vm`
- LLVM AOT: `nate build`
- LSP: `nate lsp`
- Packages: `nate init`, `get`, `lock`, `install`
- `async` / `await`
- `supervise`
- `move`, `@strict`
- `expects` / `ensures` contracts
- reflection builtins
- SQLite builtins
- extra HTTP surface, regex extras, vectors
- agent, MCP, and AI builtins
- VS Code features beyond syntax and run

## Out of 1.0

Do not mention these in getting-started docs.

- Sail web framework
- Package registry
- Debugger, web playground
- Complete generics
- Database beyond preview SQLite
- WASM, GPU, mobile, IoT, embedded
- Self-hosting the compiler in Nate
- Production AI agent platform

## Compatibility rule

1. The tree-walking interpreter implements the frozen spec.
2. VM may be preview. Every frozen example it claims to run must match
   interpreter output.
3. AOT may be preview. Document missing builtins. Do not imply C-level
   completeness.
4. `scripts/vm_parity_audit.py` is a release gate for the frozen set.

If a frozen feature works in the interpreter and fails in the VM, either
implement it or stop advertising the VM for that feature.

## Release gates

Ship `v1.0.0` only when all of these are true:

1. This file matches GitHub milestones.
2. Every frozen keyword and stdlib function has a spec and a test.
3. Conformance is green on macOS and Linux CI.
4. `examples/security.nate` is green.
5. Frozen examples match between interpreter and VM, or VM is incomplete
   and not advertised as 1.0.
6. `nate --version` prints `1.0.0`.
7. `nate run` does not dump the AST by default.
8. Root README, install guide, language guide, and CLI spec agree.
9. Preview features are named preview.
10. Changelog lists what 1.0 is and what it is not.
